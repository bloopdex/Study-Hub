ML algorithms

Fourteen classic machine-learning algorithms: linear and logistic regression, KNN, Naive Bayes, trees and their ensembles (random forest, AdaBoost, gradient boosting), SVMs, four clustering methods (k-means, hierarchical, GMM, DBSCAN) and PCA for dimensionality reduction.

Why it matters: knowing what each algorithm assumes, what it costs and where it shines lets you pick a strong model in minutes instead of trying everything.

    Key points

    • Linear models are fast and interpretable because they are weighted sums of the features.
    • Distance-based methods need scaling because large-valued features dominate distances.
    • Forests reduce variance and boosting reduces bias because one averages parallel trees and the other adds trees that fix errors.
    • Clustering methods differ in shape assumptions because k-means uses centres, GMM Gaussians, DBSCAN density and hierarchical a linkage rule.
    • PCA compresses features because correlated features share directions of variance.

    Video talking points

    Use these 5 bullets as your script outline. Say each one in your own words. Do not read them: glance at them and speak.

    1. Hook (10 sec). Ask: with fourteen algorithms to choose from, how do you know which one to try first?
    2. The big picture (30 sec). Supervised models learn from labels: linear and logistic regression, KNN, Naive Bayes, trees and ensembles, SVM. Unsupervised models find structure: k-means, hierarchical, GMM, DBSCAN and PCA.
    3. Trees and ensembles (30 sec). One tree is readable but unstable. A random forest averages many trees to cut variance; boosting adds trees one by one to cut bias.
    4. How to choose (45 sec). Walk the "Which one to pick?" flowchart: a number, linear regression or boosting; a class, logistic regression as a baseline then gradient boosting on tabular data; groups, k-means for round, DBSCAN for any shape, GMM for soft; too many features, PCA.
    5. One takeaway (10 sec). Start with a simple baseline, then move to ensembles only when the baseline is not good enough.
